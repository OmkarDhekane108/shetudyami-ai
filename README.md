# ShetUdyami.AI
**Shetkari Te Udyojak, AI Sobat.**
A smart farming ecosystem for Indian farmers, in Marathi.
## Modules
- Dudh Manager (Dairy management)
- Smart Pani (IoT irrigation)
- Bazaar (Direct selling)
- Process Hub (Onion/Potato by-product marketplace)
- AI Advisor (Marathi)
## Tech Stack
Flutter, Firebase, React, ESP32, Python
## Status
Phase 1: Dudh Manager MVP (In Progress)
